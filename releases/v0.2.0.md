# Romanian Monetary Dynamics v0.2.0

**Structural review and reproducibility milestone**

RMD v0.2.0 freezes the first post-baseline milestone in which the model's accounting, empirical-evidence, candidate-feedback and activation boundaries are represented by a substantially broader set of machine-checkable scientific contracts.

## What changed since v0.1.0

### Accounting and empirical observability

- retained the Accounting Spine as a hard stock-flow-consistent constraint;
- expanded instrument-specific rank, materialisation, provenance and reopen-condition audits without inventing bilateral allocations;
- retained **F3** as the only canonically complete stock-and-flow instrument at the current benchmark;
- advanced the integrated reference-mode gate to **9 / 10 observed modes**;
- retained **sectoral_financial_positions** as the explicit remaining reference-mode blocker after ECB, Eurostat, OECD and BNR source-boundary screening reached the current public-data limit;
- preserved missing/TBD values as unresolved rather than simulation zeros.

### Feedback architecture

All five registered structures now have explicit link-level structural/source-boundary reviews:

- Government refinancing–interest — closed candidate loop, inactive;
- Government issuance–yield — closed candidate loop, inactive;
- Bank credit–balance-sheet — closed candidate loop, inactive;
- Monetary–credit transmission — closed candidate loop, inactive;
- External FX–refinancing — **open chain**, inactive.

Across the architecture there are **22 registered links, 0 exact integrated link equations ready, 0 activation-ready structures and 0 quantitatively active feedback structures**. No closing link is invented for the external FX chain.

### Behavioural and validation governance

- validated reference behavioural mechanisms: **0**;
- behavioural closure: **inactive**;
- calibration/refit cycle: **closed**;
- candidate and deferred mechanisms retain explicit source, identification, holdout and reopen gates;
- observed targets, qualitative topology and related literature cannot silently promote a mechanism into an active equation;
- prospective and final-evaluation data remain protected by their frozen access rules.

### Delays and numerical integration

- all seven registered delay candidates remain inactive with scalar `tau = TBD`;
- no observation frequency, lag window, average maturity or average re-fixing measure is converted mechanically into a System Dynamics delay;
- explicit Euler remains the transparent reference integrator;
- constant-rate stock updates pass partition-invariance checks;
- a normalized first-order delay passes repeated time-step-halving convergence;
- the conservative System Dynamics adequacy rule remains `dt/tau < 1/3`;
- with the default quarterly `dt = 0.25 years`, a future active first-order delay requires `tau > 0.75 years` or a smaller integration step;
- integrated-model numerical robustness remains **NOT_RUN_BEHAVIOURAL_CLOSURE_INACTIVE**.

### Reproducibility and repository governance

- official/reproducible source vintages are retained with provenance and offline verification;
- Scientific CI now checks accounting readiness, materialisation/rank boundaries, dimensional consistency, behavioural parameter semantics, delay evidence, feedback-link readiness, activation criteria, System Dynamics conformity, numerical integration and cross-registry scientific state;
- trigger-aware monitoring prevents repeated unchanged-source probing from being counted as scientific progress;
- README, contribution/support surfaces and release/version governance were professionalized;
- public version changes are atomic across package, citation, changelog, release notes, tag and GitHub Release surfaces.

## What v0.2.0 does not claim

This release is **not**:

- a complete endogenous System Dynamics model;
- a calibrated macroeconomic forecast;
- a validated policy simulator;
- evidence that candidate relationships are causally identified;
- evidence that unresolved accounting cells are zero;
- permission to open protected holdouts or refit frozen mechanisms.
